# Inferno Gaming

A modern, responsive gaming team website built with HTML, CSS, and JavaScript. The website features a sleek dark theme with red and blue accents, 3D model integration, and various sections to showcase the team's divisions, tournaments, news, and more.

## Features

- **Modern Design**: Dark theme with vibrant red and blue accents
- **Responsive Layout**: Fully responsive design that works on all devices
- **3D Integration**: Interactive 3D model in the hero section using Three.js
- **Team Sections**: Red vs Blue themed FPS and Strategy divisions
- **Animated Elements**: Smooth animations and transitions
- **Dynamic Content**: Team member cards, tournament listings, and news sections
- **Contact Form**: Integrated contact form for inquiries
- **Interactive Navigation**: Smooth scrolling and responsive menu

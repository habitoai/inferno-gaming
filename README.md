# Inferno Gaming Community Website

A modern, responsive gaming community/clan website featuring a stylized flame design on a black background to represent energy, passion, and competitive spirit.

## Features

- Animated flame background and logo elements
- Responsive design that works on all devices
- Modern UI with gaming-focused aesthetics
- Sections for teams, tournaments, news, and recruitment
- Interactive elements with smooth animations
- Mobile-friendly navigation

## Project Structure

- `index.html` - Main HTML structure
- `styles.css` - CSS styling with flame animations
- `script.js` - JavaScript for interactivity

## Design Elements

- **Color Scheme**: Primarily black background with flame-inspired accent colors (red, orange, gold)
- **Typography**: Gaming-focused fonts (Orbitron for headings, Roboto for body text)
- **Animations**: Flame animations to represent energy and passion
- **Layout**: Modern, clean sections with clear hierarchy

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser to view the website
3. Customize content, images, and colors as needed

## Customization

- Update team information in the Teams section
- Add real tournament details in the Tournaments section
- Replace placeholder images with actual gaming content
- Modify the color scheme in the CSS variables section

## Browser Compatibility

- Chrome (recommended)
- Firefox
- Safari
- Edge
